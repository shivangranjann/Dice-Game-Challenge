# 🎲 Dice Duel PRO | Premium 2-Player Battle Arena

An ultra-modern, high-octane 2-player dice battle web game built with vanilla **HTML5**, **CSS3 (Glassmorphism & 3D CSS animations)**, and **JavaScript**. Featuring real-time score tracking, synthesized Web Audio sound effects, confetti celebrations, tournament modes, and full mobile responsiveness.

---

## ✨ Features

- 🎮 **3D Dice Tumbling Animations**: Realistic multi-axis rotation and scale bounce with suspenseful deceleration during rolls.
- 🎨 **Modern Cyber-Glassmorphic UI**: Ambient neon glow orbs, frosted glass containers, dynamic winner glow highlights, and glowing pedestals.
- 🏆 **Tournament & Free Play Modes**:
  - Endless Play
  - First to 3 Wins
  - First to 5 Wins
  - First to 10 Wins (triggers Champion Fanfare & victory celebration modal)
- 🔊 **Synthesized Web Audio SFX Engine**:
  - Crisp dice clatter clicks
  - Harmonic win arpeggios
  - Mellow stalemate chime
  - Championship victory fanfare
  - Mute/Unmute toggle (preference saved to `localStorage`)
- 🎉 **Canvas Confetti Engine**: Zero-dependency lightweight particle burst on round victories and championship triumphs.
- 👤 **Customizable Player Tags**: Click player names or edit pencil icons to customize battle names with persistent storage.
- ⌨️ **Quick Keyboard Shortcuts**: Hit **Spacebar** anywhere to roll instantly.
- 📜 **Live Roll History Log**: Real-time recent roll history pills.
- 📱 **Fully Responsive**: Optimized for phones, tablets, and desktop displays.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
# Clone the repository
git clone https://github.com/shivangranjann/Dice-Game-Challenge.git

# Navigate into the folder
cd Dice-Game-Challenge

# Open in your browser (Windows)
start index.html
```
